# Support and Troubleshooting

Start with [Installation](docs/Installation.md),
[Getting Started](docs/Getting%20Started.md), and
[Common issues](docs/Common%20issues.md).

For bugs, use the [bug-report form](https://github.com/redoracle/obsidian-git-vault/issues/new/choose)
and include the plugin version, Obsidian version, OS, sync backend,
expected behavior, and minimal reproduction. Try disabling automatic triggers
to isolate sync issues. Back up the vault before experimenting with conflict
resolution, encryption settings, or provider changes.

For feature requests, describe the user problem and the proposed behavior.
For code contributions, read [CONTRIBUTING.md](CONTRIBUTING.md).

**Security vulnerabilities must be reported privately**, using
[SECURITY.md](SECURITY.md). Never submit access tokens, credentials,
private notes, or unsanitized logs in public issues or attachments.
